# DarwinGodelMachine_ARA
The ARA format for "Darwin Gödel Machine: Open-Ended Evolution of Self-Improving Agents". 

There is an effort to move scientific CS papers into AI Age, "The Last Human-Written Paper:
Agent-Native Research Artifacts" (https://arxiv.org/pdf/2604.24658) signed on by authors from 25 organizations+universities. They want to transform the current narrative structure into a directory tree of MD files to make it more easily producible and readable by agents. All open source. It is called the ARA format. It is especially good for using agents to do the work, and for agents doing the research on their own, hence the title. I ran the "compiler" which transforms a pdf+github code into this form. 

This is the ARA format for "Darwin Gödel Machine: Open-Ended Evolution of Self-Improving Agents" (https://arxiv.org/abs/2505.22954) The compilation using orchestra-research tools (open source) took 30min. to produce from the axiv.org paper plus the github code using Claude Code (adding code makes it slower). The paper was accepted at ICLR 2026.  

I think it is a great idea. The conceptual slots in the format encourage good, reproducible research. I suppose for the traditional human beings who want to read offline, the ARA format could be input to a pdf generator for narrative form.
